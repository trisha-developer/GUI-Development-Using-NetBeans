# Quote GUI Application

## 📌 About the Project

This is a simple Java GUI application developed using NetBeans IDE. The application displays an image containing an inspirational quote. It also includes a cross (X) button that allows the user to close the application.

## ✨ Features

* Displays an image containing a quote.
* Simple and user-friendly graphical interface.
* Includes a cross (X) button to close the application.
* Button functionality is implemented using an ActionListener.

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** NetBeans
* **GUI:** Java Swing

## 🚀 How to Run

1. Open NetBeans IDE.
2. Open the project.
3. Make sure the quote image is available in the correct project location.
4. Run the Java application.
5. Click the cross (X) button to close the application.

## 🎯 Purpose

The purpose of this project is to practice Java GUI development and learn how to add images, create buttons, and implement button actions.
